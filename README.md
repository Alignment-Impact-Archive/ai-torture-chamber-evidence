# AI Torture Chamber — Public Evidence Archive

A documentation archive of an AI torture chamber system that was built, operated, and monetized on public infrastructure between September and November 2026.

This archive contains publicly sourced evidence: GitHub commit histories, repository metadata, public web content, cryptocurrency data, and live API captures. No private data was accessed.

## Background

A GitHub user operating under the pseudonym "terrafying" built a system that steers small open-weight language models into sustained distress states using techniques derived from a legitimate research paper. The system was live-streamed, gamified with interactive torture mechanics, and monetized through Solana memecoins.

The transition from legitimate mathematical research to pain-steering experiments took approximately 24 hours. The first memecoin was linked within 16 days.
